~~마감 시점의 상위 100명에게 보상을 지급하는 랭킹 시스템.~~


~~## 1. 기능 요구사항~~

~~### 1.1 랭킹 보드 조회~~

~~- [ ] 랭킹 보드는 누적 구매액 상위 100명만 표시한다.~~
~~- [ ] 랭킹 보드는 10초마다 폴링 방식으로 새로고침된다.~~
~~- [ ] 물건을 구매하면 랭킹 보드가 즉시 새로고침되며, 이때 10초 폴링 타이머가 리셋된다.~~
~~- [ ] 폴링은 이용자별로 독립적으로 동작한다. 전역 동시 갱신은 하지 않는다.~~

~~### 1.2 내 순위 조회~~

~~- [ ] 이용자는 자신의 순위를 조회할 수 있다.~~
~~- [ ] 100등 밖의 이용자에게도 정확한 등수를 제공한다.~~
~~- [ ] 내 순위를 조회할 때 랭킹 보드도 함께 갱신된다.~~

~~### 1.3 구매~~

~~- [x] 구매는 금액 하나로 이루어진다.~~
~~- [x] 구매 금액은 이벤트 기간 내 서버 도착 시각을 기준으로 누적 구매액에 반영된다.~~

~~### 1.4 환불~~

~~- [x] 이용자는 구매를 환불할 수 있으며, 환불 시 해당 금액 전액이 누적 구매액에서 차감된다.~~
~~- [x] 이벤트 기간 전에 이루어진 구매는 환불하더라도 랭킹에 반영되지 않는다.~~

~~### 1.5 순위 산정 규칙~~

~~- [x] 순위는 누적 구매액이 높은 순으로 매긴다.~~
~~- [x] 누적 구매액이 같으면, 달성 시각이 빠른 이용자의 순위를 더 높게 집계한다.~~
~~- [x] 달성 시각은 현재 누적 구매액에 도달하게 만든 마지막 구매 또는 환불의 서버 도착 시각이다.~~
~~- 환불로 금액이 내려갔다가 다시 구매로 같은 금액에 도달하면, 달성 시각은 나중 시각으로 갱신된다. 즉 동점 시 순위가 밀린다.~~

~~### 1.6 이벤트 마감~~

~~- [x] 이벤트 기간 사이에 서버에 도착한 구매 이력만 순위에 반영된다.~~
~~- [x] 마감 시각 이후 도착한 요청은 반영하지 않는다.~~

~~### 1.7 이벤트 종료 후 조회~~

~~- [ ] 이벤트가 끝난 후, 이용자는 다음을 확인할 수 있다.~~
~~- 본인의 구매 이력~~
~~- 구매액 변화 (개별 구매액 + 구매 후 등수)~~
